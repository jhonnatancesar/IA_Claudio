# RFCs

Propostas técnicas discutidas antes de virarem decisão (ADR) ou implementação
direta — úteis para desenhos que envolvem múltiplas alternativas ou impacto amplo
(ex.: desenho definitivo do `LocalLLMProvider`, protocolo de replanejamento).

Nenhuma RFC foi criada ainda nesta organização inicial. Convenção de nome sugerida
(mesmo padrão do repositório de referência): `RFC-NNN-titulo-curto.md`.
